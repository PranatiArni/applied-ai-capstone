Daily Study Tracker
A lightweight Flask web app for logging what you study each day and reviewing your learning over time.

Features:
Add daily study entries with:
- Date
- Subject
- Notes

View all entries in a simple timeline (newest first)
Filter entries by subject
In-memory storage (no database required)

Getting Started:
1. Clone the project
git clone <your-repo-url>
cd applied-ai-capstone
2. Install dependencies
pip install -r requirements.txt
3. Run the app
flask run

Then open:

http://127.0.0.1:5000
